# mimi_typh

Личный сайт в стиле персонажа Mimi Typh.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub
2. Загрузи **все** файлы из этой папки в корень репозитория
3. В Settings → Pages выбери ветку `main` и папку `/ (root)`
4. Сайт будет доступен по адресу `https://твой-ник.github.io/название-репо/`

## Треки (музыкальный плеер)

Чтобы треки реально играли на сайте:

1. Создай папку `music/` (она уже есть)
2. Положи туда mp3-файлы с такими именами:

| Файл                  | Трек                          |
|-----------------------|-------------------------------|
| `awake.mp3`           | Awake — russianmafiaextra     |
| `cherniy.mp3`         | Черный — CUPREOUS, DJ WESSTAG |
| `polukrovka.mp3`      | Полукровка — ICEGERGERT       |
| `dora-dura.mp3`       | Дора дура — Дора              |
| `2000-baksov.mp3`     | 2000 баксов — Алексей Марковников, Диспетчера |
| `echo.mp3`            | Эхо — The Chemodan Clan, Пика |
| `tamagochi.mp3`       | Тамагочи — лил кидд           |

После этого плеер начнёт их проигрывать.

## Что можно менять

| Место | Что менять |
|-------|------------|
| `index.html` → блоки `.card` | Заголовки и тексты двух карточек |
| `index.html` → `.modal-body` | Текст окна «Обо мне» |
| `avatar.jpg` | Своя аватарка |
| `bg-video.mp4` | Фоновое видео |
| `style.css` → `:root` | Цветовая палитра |
| `music/` | mp3-файлы треков |
